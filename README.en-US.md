# 3D Visualization Editor

> A vue3+vite 3D model online editor based on the [three.js](https://threejs.org/) engine

## Features

-   ✅ Basic layout (tools, layers, properties, scene)
-   ✅ Basic layers
-   ✅ Layer search
-   ✅ Layer drag-and-drop sorting
-   ✅ Layer name editing
-   ✅ Basic tools
-   ✅ Basic tools - geometries
-   ✅ Basic tools - planes
-   ✅ Basic tools - selectors
-   ✅ Basic properties
-   ✅ Basic properties - camera
-   ✅ Basic properties - transform
-   ✅ Basic properties - basic geometry attributes
-   ✅ Basic properties - basic materials
-   ✅ Basic tools - plane circle
-   ✅ Basic tools - text
-   ✅ Basic properties - all materials
-   ✅ Global properties - all lights
-   ✅ Import 3d model import management
-   ☑️ Basic tools - pen path
-   ☑️ Boolean operations `npm i tthreebsp` Compatible with the current version of three based on tthreebsp
-   ☑️ Layers grouping management
-   ☑️ Library resource management
